Calibration Data and Results
============================

The `CNit Model Calibration and Results dataset on Zenodo
<https://doi.org/10.5281/zenodo.18116573>`_ provides the calibrated parameters,
forcing data, and calibration targets used by the CMIP6 ESM and TRENDY DGVM
emulation examples.

Download the files listed in :doc:`Emulation Workflows <../example>` and place them
in the project's ``data/`` directory before running the notebooks.
