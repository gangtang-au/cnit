Calibration Data and Results
============================

The `CNit Model Calibration and Results <https://doi.org/10.5281/zenodo.18116573>`_
dataset on Zenodo provides the calibrated parameters, forcing data, and calibration
targets used by the CMIP6 ESM and TRENDY DGVM emulation examples.

Download the files listed in the :doc:`CMIP6 ESM emulation <../examples/cmip6-esm>`
and :doc:`TRENDY DGVM emulation <../examples/trendy-dgvm>` pages and place them
in the project's ``data/`` directory before running the notebooks.
